# Smart Payment Reminder Agent

## Overview
An Agentic AI workflow that automates payment reminders using Zapier Agents, Google Sheets, Gmail, and Google Gemini AI.

## Features
- Sends payment reminders twice daily.
- Reads pending invoices from Google Sheets.
- Generates AI-powered reminder emails.
- Sends one email per pending invoice.
- Updates payment status upon confirmation.

## Tech Stack
- Zapier Agents
- Google Sheets
- Gmail
- Google Gemini AI
